# Beatriz Martins Gomes Silva — Portfolio

Personal portfolio focused on **Data Science, Machine Learning, Data Analytics and engineering-oriented digital systems**.

## Recommended deployment

Create a public repository named:

```text
biamgomess.github.io
```

With GitHub Pages enabled, the site can be published at:

```text
https://biamgomess.github.io/
```

## Design direction

Version 2 uses a lighter engineering / technology visual system inspired by the purple, blue and white language often used in contemporary engineering and digital-transformation branding.

Key elements:

- light neutral background for readability;
- purple and blue technical accents;
- circular profile portrait;
- interactive technical-skills explorer;
- project carousel with consistent schematic visuals;
- explicit GitHub and live-demo calls to action;
- responsive desktop and mobile layouts.

## Deploy with GitHub Pages

1. Create the public repository `biamgomess.github.io`.
2. Upload the contents of this package to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.

## Editing

No framework or build step is required.

- Edit content in `index.html`.
- Edit the visual system in `css/styles.css`.
- Small interactions are in `js/script.js`.
